# Judicial Management System

A Python-based web application for managing court cases, hearings, judges, clerks, and case records through a web interface.

## Features

- User login and authentication
- Judge dashboard
- Clerk dashboard
- Admin dashboard
- Court case management
- Hearing management
- Adjournment management
- Case analytics
- Database integration

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- Jinja2
